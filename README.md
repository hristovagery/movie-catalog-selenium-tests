# Movie Catalog Selenium Tests
This repository contains Selenium automation tests for the Movie Catalog web application.
The tests cover functionalities such as user login, browsing movie listings, and searching for movies.
## Prerequisites
* Google Chrome browser installed
* ChromeDriver compatible with your Chrome version
## How to run the tests
1. Clone this repository.
2. Navigate to the project directory.
3. Run the test suite using your testing framework (e.g., `pytest`).
